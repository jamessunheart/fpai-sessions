# Cohort 1 Application — Apprentice Studio

> **DRAFT — for human review before publication. Becomes the public application form.**

## Read this first

We're selecting **4 to 6 apprentices** for Cohort 1.
We will reject most applicants. That is part of how this program works.

This is a **10-week, full-time, hybrid** program (onsite week 1, remote weeks 2-9, onsite week 10).

You will:
- Build a real, shippable product using FPAI's infrastructure.
- Pair daily with an AI co-builder (Aria) instanced for you.
- Ship by week 8 or pivot.
- Keep 70% equity in what you build.

You will not:
- Pay tuition.
- Get a salary (we cover housing, food, tools, API credits).
- Coast. There is no place to hide in a cohort of six.

## Three-stage selection

**Stage 1 — Application + Portfolio.** This form. ~30 minutes.
**Stage 2 — 48-hour build challenge.** We send you a brief; you ship a small AI service + reflection. Top 12 applicants advance.
**Stage 3 — Conversation.** With the program owner and the founding apprentice. Values, energy, fit. Top 4-6 are accepted.
