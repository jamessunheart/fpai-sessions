Step-by-step (click to expand)

🎯 What you need to copy:

  1. App ID
  2. App Secret
  3. Access Token (System User)
  4. Ad Account ID (format: act_XXXXXXXXX)
  5. Pixel ID

Step 1: Go to developers.facebook.com/apps

Step 2: Click "Create App" → Select "Business" → Name it "Full Potential Ad Portal"

Step 3: In app dashboard, click "Add Product" → Find "Marketing API" → "Set Up"

Step 4: Go to Settings → Basic:

  • Copy App ID
  • Click "Show" and copy App Secret

Step 5: Go to Business Settings → System Users

  • Create System User (Admin role)
  • Add your app to the system user
  • Generate Token with: ads_management, ads_read, business_management
  • Copy the Access Token

Step 6: Go to Business Settings → Ad Accounts

  • Copy the Ad Account ID (starts with act_)

Step 7: Go to Events Manager

  • Create a Pixel if you don't have one
  • Copy the Pixel ID

📝 Once you have all 5 values:

Message James with this format:

META_APP_ID=your_app_id
META_APP_SECRET=your_app_secret
META_ACCESS_TOKEN=your_token
META_AD_ACCOUNT_ID=act_xxxxx
META_PIXEL_ID=your_pixel_id
