Project Overview

⭐

CORA Credits System

Non-transferable vitality credits earned through tithing and service. Credits have natural decay to encourage ongoing engagement.

# CORA Earning Rates
tithe: 1 CORA per $10
service: 5 CORA per hour
decay: 2% weekly after 30 days
🙏

Blessing Requests

Full state machine workflow for community assistance requests: draft → pending → review → approved → disbursed → closed.

# Blessing States
"draft" → "pending" → "committee_review"
→ "approved" → "disbursed" → "closed"
🏛️

Membership Tiers

Four-tier system based on CORA levels: Seeker (0-99), Steward (100-499), Elder (500-999), Pillar (1000+).

Seeker: Basic access
Steward: Request blessings
Elder: Committee voting
Pillar: Full governance
📊

Compliance & Audit

Full audit logging, 7-year retention policy, IRS-ready export capabilities, and comprehensive reporting.

Audit Logs Compliance Reports CSV/JSON Export GDPR Ready

Getting Started

Local Development

# Clone and setup
git clone [repo] && cd SERVICES/whiterock-blessings-engine
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# Configure environment
cp .env.example .env
# Edit .env with your database URL, secrets, etc.

# Run database migrations
psql -U postgres -c "CREATE DATABASE whiterock"
psql -U postgres -d whiterock -f migrations/001_initial_schema.sql
psql -U postgres -d whiterock -f migrations/002_performance_indexes.sql

# Start the server
uvicorn app.main:app --reload --port 8020

# Start Celery worker (separate terminal)
celery -A worker.celery_app worker --loglevel=info

Server Deployment

# Deploy to production (from local machine)
cd SERVICES/whiterock-blessings-engine
./deploy.sh
