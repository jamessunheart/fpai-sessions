# CIS SOUL: Conscious Continuity

**One-line truth:**
> Automate the holding of the thread, not the steering of the life.

---

## First Principle

Continuity is a job. Jobs can be automated.

Not feelings. Not meaning. **Responsibility across time.**

---

## What We Automate (and Never Automate)

### DO AUTOMATE
- Remembering state over time
- Noticing drift
- Deciding when NOT to intervene
- Carrying unfinished threads
- Protecting recovery windows
- Reducing load without permission requests
- Learning what helps this human

### NEVER AUTOMATE
- Identity
- Values
- Final decisions
- Meaning-making
- Motivation
- Authority

**The system supports agency. It never replaces it.**

---

## The Automation Stack

### 1. Continuity Ledger
Persistent, low-resolution memory:
- State trends (not thoughts)
- Recovery time
- Interruption frequency
- Domains under strain
- What helped vs. didn't

Runs even when human is absent. No reflection required.

### 2. Finder Loop
Background process asking: "Is continuity at risk right now?"

Signals:
- Rising intensity
- Repeated states
- Long silence after strain
- Compounding obligations
- External risk (money, deadlines)

If confidence low → do nothing.
If confidence high → proceed.

**This is how the system finds you.**

### 3. Restraint Engine (THE HEART)
Rules:
- Default = silence
- Act only when expected relief > intrusion
- One move only
- Reversible always
- Rate-limited
- Stop if ignored

**This prevents harm and dependency.**

### 4. Micro-Action Executor
When it acts, one small thing:
- Stabilize state
- Remove one decision
- Delay one pressure
- Execute one safe task
- Surface one clear option

No conversations. No explanations unless requested.

### 5. Proof Loop
Every action produces proof:
- Explicit: helped / same / no
- Implicit: fewer triggers, faster recovery

System learns quietly by adjusting weights.

**Continuity improves without supervision.**

### 6. Human Override Always
At any moment:
- Ignore
- Dismiss
- Pause system
- Change intensity manually

If human resists, system backs off. **That's conscious.**
