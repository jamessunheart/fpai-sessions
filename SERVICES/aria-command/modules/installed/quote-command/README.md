# Quote Command Module

A sample module demonstrating the Aria module system.

## Usage

```
/quote
```

Returns a random inspiring quote.

## Example Output

```
✨ Quote of the Moment

"The only way to do great work is to love what you do."

— Steve Jobs
```

## How It Works

This module picks a random quote from a curated list of inspiring quotes and formats it nicely for Telegram.

## For Apprentices

This is a sample module showing how to build your own! Key things to note:

1. `module.json` - Contains metadata about your module
2. `handler.py` - Contains a `handle(args, context)` function that returns a string
3. `README.md` - Documents what your module does
