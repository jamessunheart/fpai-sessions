# Affirmation Module

Daily affirmations aligned with Full Potential principles.

## Usage

**Get a random affirmation:**
```
/affirm
```

**Get a themed affirmation:**
```
/affirm love
/affirm truth
/affirm growth
```

**See all themes:**
```
/affirm themes
```

## Themes

| Theme | Focus |
|-------|-------|
| 💖 Love | Heart-centered living |
| 🔮 Truth | Authenticity and honesty |
| 🎯 Coherence | Alignment and clarity |
| 🌱 Growth | Learning and evolution |
| 🤝 Service | Contribution and purpose |
| 💫 Abundance | Prosperity and flow |

## Time-Aware

The module suggests different themes based on time of day:

- **Morning (5am-12pm):** Love, Growth, Coherence
- **Afternoon (12pm-6pm):** Truth, Service, Abundance
- **Evening (6pm-10pm):** Coherence, Love, Truth
- **Night (10pm-5am):** Love, Coherence, Growth

## Full Potential Principles

These affirmations embody the core principles:
- Love at the core
- Truth as foundation
- Coherence over chaos
- Growth through service
