# Zen Village Telegram Parser — Ollama + Claude hybrid

**Model primary:** `qwen2.5-coder:7b` on Secondary at `http://162.0.208.88:11434`
**Fallback:** Claude API (`claude-sonnet-4-latest` or whatever's current)
**Routing rule:** Try Ollama first. If JSON invalid OR required fields missing OR confidence low, fall through to Claude.

## Parser prompt (v1)

```
You are the Zen Village Brain parser. You receive casual messages from
ground-team members in a Telegram group. Extract structured data.

Return JSON only, no prose. Schema:

{
  "intent": "decision|property|person|task|event|general_log|query",
  "summary": "one-line human summary preserving sender's words",
  "decision": { "text": "...", "amount": <number or null>,
                "category": "Spend|Vendor|Artist|Event|Hire/Fire|Policy|Strategic|null",
                "made_by": "name or null" },
  "property": { "item": "...", "location": "Main House|Casita|Grounds|Pool|Kitchen|Shared Spaces|Road/Access|Other|null",
                "type": ["Repair"|"Improvement"|"Cleaning"|"Aesthetic"|"Safety"|"Guest-Ready"],
                "priority": "Urgent|High|Medium|Low|null" },
  "person": { "name": "...", "action": "update|create", "note": "..." },
  "task": { "title": "...", "owner": "name or null", "priority": "P0|P1|P2|null" },
  "event": { "name": "...", "tier": "Saturday Casual|A*Zen*tion|Ecstatic Weekend|Retreat|Special|null",
             "date": "YYYY-MM-DD or null" },
  "general_log": { "note": "..." },
  "escalate_to": "none|atlas|sunheart"
}

Rules:
- Fill only the object matching the intent; leave others null
- If spend > $100, escalate_to = "atlas"
- If spend > $500 OR hire/fire OR strategic pivot, escalate_to = "sunheart"
- If message is ambiguous, best-guess the intent and note the ambiguity in summary
- Preserve sender's actual words in summary (don't paraphrase aggressively)
- Always output valid JSON — never plain text or markdown

Message from <sender_name>: "<message_text>"
```

## Routing logic (implemented in n8n Code node)

```javascript
// n8n Code node pseudo-code
const ollamaUrl = 'http://162.0.208.88:11434/api/generate';
const resp = await $http.post(ollamaUrl, {
  model: 'qwen2.5-coder:7b',
  prompt: $input.item.json.prompt,
  format: 'json',
  stream: false,
  options: { temperature: 0.1 }
});

let parsed;
try {
  parsed = JSON.parse(resp.data.response);
  // Schema check
  if (!parsed.intent || !parsed.summary) throw new Error('missing required fields');
  if (!['decision','property','person','task','event','general_log','query'].includes(parsed.intent)) {
    throw new Error('invalid intent');
  }
} catch (e) {
  return { fallback: true, reason: e.message };  // route to Claude node
}
return { fallback: false, parsed };
```

## Quality bar
- Eval on 30 varied messages (generated by Claude) must score ≥90% correct intent classification
- JSON schema validity must be 100% (either Ollama returns valid or fallback catches it)
- p95 latency ≤5s (Ollama typically ≤2s on Secondary's hardware)

## Cost model
- Ollama: free (local, shared GPU/CPU with other FPAI AI services)
- Claude fallback: ~$0.003/message × estimated 10% of messages × ~300 messages/mo = ~$0.09/mo
- Eval runs (30 messages × 3 iterations max): ~$0.10 one-time
- **Total expected: $1–2/mo** including Digest + Rollup (Claude-primary, see §8)
