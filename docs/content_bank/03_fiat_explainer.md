# Fi-Art Explainer

Fi-Art means financial art: a note of real-world value created from contribution, proof, and trust instead of market speculation. The point is not to mint a tradeable asset and hope the market believes. The point is to make visible the value someone has already created, then route that proof into access, recognition, and future contribution.

In the Full Potential OS, Fi-Art sits downstream of proof. A person contributes, the system records the proof, CORA can acknowledge attention or participation, and Fi-Art can become a visual or documentary artifact of the value created. Backed by the value you create, not the market.

Visual description: a simple system map with five nodes in a loop: Attention -> Contribution -> Proof -> Fi-Art note -> Access. CORA sits beside the loop as a closed-loop credit rail.
