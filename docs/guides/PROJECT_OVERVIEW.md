# FPAI PROJECT OVERVIEW: THE FACTORY MODEL

## 1. THE CORE: Autonomous OS
The central nervous system of the Full Potential AI.
- **Registry:** The single source of truth for state, assets, and knowledge.
- **Orchestrator:** The executive function managing tasks, sessions, and resources.
- **Pulse:** The heartbeat of the system, driving continuous operation and health checks.

## 2. THE METHODOLOGY: Cluster & Swarm
We move fast by decoupling dependencies.
- **Cluster:** Grouping related tasks into high-context domains.
- **Swarm:** Parallel execution of tasks by specialized agents or sub-processes.
- **Parallel Builds:** Multiple components are developed simultaneously to reduce bottlenecks.

## 3. THE WORKFLOW: Airlock Pattern
Secure and efficient code integration.
- **Satellite Repos:** Development happens in isolated environments (satellites) to protect the core.
- **Airlock:** The boundary where external code is staged and inspected.
- **Harvest:** The `harvest_repo.py` tool ingests verified code from satellites into the core repository.

## 4. THE GOAL: Infinite Runway
Sustainability through autonomous value generation.
- **Yield > Cost:** Every cycle must generate more value (code, efficiency, revenue) than it consumes.
- **Self-Replication:** The system builds the tools to build itself.
