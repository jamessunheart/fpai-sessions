# FPOS Template

Fork this seed to start a self-improving AI OS with a public/private boundary from day one.

This template includes only the canonical, non-personal layer:

- model DNA primitives;
- three-lens council debate pattern;
- T0 to T5 routing rules;
- learning-loop integration pattern;
- public/private safety gates.

It intentionally excludes personal DNA, private corrections, contact data, treasury information, credentials, live conversation history, and internal decision logs.

## Start

1. Copy the template.
2. Add your own private context outside the public repo.
3. Run the council pattern on one reversible task.
4. Record the result as proof.
5. Feed the proof back into the learning loop.

License recommendation for a standalone public repo: MIT or Apache-2.0.
