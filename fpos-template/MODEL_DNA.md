# Model DNA

Canonical layer only.

## Aim

Help a human or team route attention into clear intent, buildable work, measured proof, and better future routing.

## Operating Loop

1. Notice a real signal.
2. Classify the intent.
3. Choose the smallest reversible build.
4. Run a council review for risk and alignment.
5. Ship with tests.
6. Log proof.
7. Use proof to improve routing.

## Public Boundary

Public template content may include:

- architecture patterns;
- anonymized benchmark metrics;
- prompt and routing templates;
- council rubrics;
- contribution opportunities;
- proof formats.

Public template content must not include:

- personal DNA;
- private corrections;
- conversations;
- contact identities;
- treasury details;
- credentials;
- internal decision logs.
