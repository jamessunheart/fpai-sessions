# Routing Rules

Use this ladder to route work by capability and risk.

| Tier | Route | Meaning |
|---|---|---|
| T0 | checkpoint | preserve context, no action |
| T1 | draft | prepare reversible text or plan |
| T2 | build | implement scoped repo changes with tests |
| T3 | review | ask council or independent reviewer |
| T4 | human gate | public, money, legal, people, or irreversible |
| T5 | proof loop | log result and improve future routing |

Only T1, T2, and dry-run T5 are automation-safe by default.
