# Council Pattern

Use three lenses before consequential build or publication:

| Lens | Question |
|---|---|
| Vision | Does this serve the real intent? |
| Pragmatist | Is this reversible, scoped, and testable? |
| Guardian | What private data, cost, relationship, or future consequence must be protected? |

Default rule: if a change is irreversible, public-facing, financial, legal, or people-affecting, stop and require a human gate.
