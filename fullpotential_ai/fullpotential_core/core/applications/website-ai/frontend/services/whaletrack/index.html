Trading loop

WhaleTrack executes the 10-step magnet loop: read whale direction, score magnets, select the cheapest flow, wait for alignment, enter with momentum/retrace/reversal discipline, exit at the magnet (or front-run / sweep snapback), then look for reversals.

Bridge service — live data feed

Keep WhaleTrack fed with real candles and log paper trades. Swap exchanges via env vars (Kraken, KuCoin, Bybit…) and move from paper → live when you inject API keys. 

git clone https://github.com/fullpotential-ai/whaletrack-magnetic-trader.git
cd whaletrack-magnetic-trader
pip3 install -r bridge/requirements.txt
export BRIDGE_EXCHANGE=kraken
export BRIDGE_SYMBOL=BTC/USD
export WHALETRACK_API_BASE=http://198.54.123.234:8600
python3 bridge/bridge_service.py

Paper trades are stored in bridge/paper_trades.json with entry/exit context. Hook this to your telemetry bus or let Nexus ingest it.
