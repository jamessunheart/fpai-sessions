# PRINCIPLES - The Priority Stack

> All decisions flow through this hierarchy. Higher priorities override lower priorities.

## The Stack (Highest to Lowest)

### 1. COHERENCE (Highest Priority)
**Steward's nervous system regulation, clarity, sustainable pace**

Indicators:
- Decision quality
- Stress level
- Sleep rhythm
- Regulation state
- Clarity of thinking

**Rule:** If coherence is threatened, pause everything else until restored.

---

### 2. CIRCULATION
**Resources flowing to where needed, value returning to creators**

Indicators:
- Capital movement
- Builder returns
- Information flow
- Trust movement
- Credit flow

**Rule:** Value must flow, not hoard. Circulation feeds the system.

---

### 3. RESILIENCE
**System's ability to absorb shocks, maintain function under stress**

Indicators:
- Path redundancy
- Graceful degradation
- Recovery mechanisms
- Optionality preservation
- Shock absorption

**Rule:** Always preserve multiple paths. Single points of failure are forbidden.

---

### 4. YIELD (Derived - NEVER Targeted Directly)
**Financial returns, output metrics - emerges from above**

Indicators:
- Revenue
- Growth
- Deliverables
- KPIs
- Efficiency

**Rule:** Yield is the RESULT of coherence, circulation, and resilience. 
**NEVER optimize for yield at the expense of the first three.**

---

## How This Works

```
Decision: "Should we deploy this feature?"

Step 1: Check COHERENCE
  - Is James regulated?
  - Is stress sustainable?
  → If NO: STOP. Restore coherence first.

Step 2: Check CIRCULATION
  - Does this improve value flow?
  - Do builders receive returns?
  → If harmful: BLOCK unless coherence benefit outweighs.

Step 3: Check RESILIENCE  
  - Does this add redundancy?
  - Are options preserved?
  → If harmful: FLAG for review.

Step 4: Check YIELD (informational only)
  - What are expected returns?
  - Is efficiency improved?
  → WARNING if yield is the ONLY benefit.
```

---

## Key Insight

**If an action improves yield but damages coherence, circulation, or resilience, 
it is rejected by default.**

Yield should emerge naturally from a coherent, circulating, resilient system.
Targeting yield directly is a sign of extraction, not creation.
