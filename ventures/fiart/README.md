# Fi-art — Spec Set

Money-inspired art that teaches monetary literacy and bridges into real-world capacity. A living museum of value where the exhibits can be used.

**One sentence:** Anyone can create Fi-art · verified creators can create redeemable Fi-art · approved liquidity stewards can support fiat exits — and every note carries a Truth Panel that makes what-backs-it visible.
