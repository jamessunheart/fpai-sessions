How a blueprint evolves

  1. Store — each blueprint is a markdown file in bp/, indexed in the registry. Git is the memory: every version preserved forever.
  2. Rate — anyone rates 1–5. Witnessed feedback, not opinion polls: ratings attach to versions.
  3. Propose — submit an evolution below, via the Guide, or straight through git.
  4. Evolve — a steward merges the strongest proposal. Version bumps. History updates itself from git.
