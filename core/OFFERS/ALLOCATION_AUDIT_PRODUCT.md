# The Product — Free Allocation Intelligence Audit → Organizational Capability Expansion

> **Front door:** Free Allocation Intelligence Audit (executive, not "AI readiness").
> **Real product:** Organizational Capability Expansion — the audit only *diagnoses* where
> capability can grow. **North star:** Future Capability. **Engine/moat:** Allocation Intelligence.

## The workflow (front door → recursion)
Future ("what are you building?") → Resource Map → Allocation Audit (AI analyzes every
allocation) → **Allocation Score** (strengths · waste · bottlenecks · missed opportunity)
→ Intelligence Blueprint → Choose (self-implement OR FPOS builds) → Builder missions →
Brain learns → future audits improve → **re-audit quarterly** → repeat.

## The three reinforcing loops
- **Client:** audit → implement → improve → re-audit (recurring executive-intelligence function, not one-time consulting).
- **Builder:** mission → build → document → improve Brain → better missions. *Builders build Allocation Intelligence, not just software.* Missions are CREATED BY the audit, not chosen.
- **Brain:** knowledge → templates → agents → better audits → better recommendations → better knowledge.

## The moat (the real strategic advantage)
Every recommendation either **deploys existing capability** or **creates new capability that
strengthens the system for everyone who follows.** With client permission, every completed
audit teaches FPOS how organizations allocate capital/time/people/knowledge/AI — proprietary
cross-industry allocation patterns. **Every audit makes the next audit more intelligent.**
Clients aren't buying improvements for themselves; they join a network that compounds.

## ⚠️ Sequencing discipline (Ember's honest guardrails — how to survive the cold start)
The flywheel is beautiful *at scale*; the danger is the first 10 clients, before compounding kicks in. Don't let the elegant end-state hide the unglamorous cold start:
1. **Narrow the FIRST audits to the measurable wedge (capital / AI-spend).** Deliver ONE
   dimension deep + undeniable → get the case study → THEN broaden to the full 6-dimension
   executive audit as the Brain compounds. Launching with the full broad audit, free, hand-
   delivered, is a delivery trap.
2. **Warm-first, not cold-first.** A free broad audit is a *favor* to a warm contact (high
   conversion). Fully cold + free + broad = low conversion, high delivery cost, brand risk.
3. **Builders LAST, not step 7.** Prove the audit with James + Ember (1–3 clients) BEFORE
   activating the Builder ecosystem — else you staff empty missions (Law 8).
4. **Manual-first, tool-second.** Build the audit engine FROM the first hand-delivered audits
   (recursion), not before (empty-seats trap). See [[AUDIT_WORKSHEET]].
5. **Run it on FPOS itself, publicly.** Client #0 = us. Publish our own Allocation Score
   improving over time (brain versioning + metabolism + RCA are the evidence). Radical
   transparency = the strongest proof the engine works.
