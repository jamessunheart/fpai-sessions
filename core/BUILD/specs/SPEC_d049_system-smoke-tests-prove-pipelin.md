## New file: tools/test/smoke_test.py

Runs 7 smoke tests against the LIVE system. Each test:
  1. Does a real operation (or simulates one with TEST_ prefix to avoid side effects)
  2. Checks the expected outcome in brain_index
  3. Logs PASS/FAIL + latency to ops_ledger
  4. On FAIL: sends immediate TG alert (do not wait for morning digest)

## New file: tools/test/spec_checker.py

Deeper gap detection — runs weekly (not every 6h, more expensive):
  For each recently built decision:
    1. Load the original build spec from brain_index.decisions.build_spec
    2. Load the actual diff from the build branch (git log)
    3. Run claude -p (--effort high): 'Does this diff implement what this spec required?        List what is missing or diverged. JSON: {matches: bool, gaps: [str], risk: low|med|high}'
    4. Log gaps to ops_ledger: event=spec_gap, decision_id=X, gaps=[...]
    5. If risk=high: immediate TG alert
    6. Include in weekly digest section: SPEC COMPLIANCE REPORT
This is the 'fresh eyes checks work against the spec' pattern from Fable 5 guide.
