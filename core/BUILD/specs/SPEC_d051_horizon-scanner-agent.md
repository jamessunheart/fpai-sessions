The build loop is reactive — James names a gap, it builds. Nothing watches for what is coming before he names it.
The most immediate use case: d045 (Life Data Intake) is starting to produce signal (mood, energy, events, context). Without a scanner, that signal becomes another inbox. With one, the system surfaces the pattern before James has to notice it.

The Horizon Scanner is not a digest agent. It does not summarize what happened. It watches active signal streams and surfaces what is ABOUT TO MATTER — before James has to name it.

## What it scans

### Signal stream 1: Life Data (d045 output — brain_index.life_events or equivalent)
- Reads last 7 days of life data entries
- Detects: energy trends (low 3+ days = flag), repeated themes (same topic 3+ times = emerging priority), unresolved friction (open items with no action taken), mood slope (declining = system may need to lighten load)

### Signal stream 2: Buildstream (brain_index.decisions + ops_ledger)
- Reads: builds queued vs building vs blocked vs merged vs reverted
- Detects: stall patterns (same decision blocked 2+ times = spec problem), revert streaks (import failures = system instability), proposal drought (council not proposing = queue stale or system overloaded), blocked builds accumulating

### Signal stream 3: Interaction patterns (brain_index.thread + tg_messages)
- Detects: silence (no interaction 24h+ = James unavailable or disengaged), topic recurrence (same question 3+ times = signal not retained or resolved), late-night session patterns (possible overload)

## What it does NOT do
- Does not summarize the past (morning digest does that)
- Does not propose builds (council does that)
- Does not wait for James to ask
- Does not produce a list of everything it saw

## Output: one sharp signal per scan — or silence
Run every 6h. If nothing crosses a threshold: silent. No TG message.
If signal: one TG message, max 3 sentences:
  - What pattern was detected
  - Why it matters now (not FYI — what this unlocks or warns against)
  - One optional question if James's input would sharpen the response

Example (cross-signal): "Low energy flagged 3 days in a row while 4 builds are queued. System is building but you may not have capacity to absorb what arrives. Worth pausing the council until Thursday?"
Example (stall): "d034 (Hermes) blocked twice. Spec may be too broad for Codex. Worth a manual look before it builds again."

## New file: tools/horizon/scanner.py
- Reads all 3 signal streams from brain_index
- Computes threshold signals per stream (thresholds in tools/horizon/horizon_config.json)
- Cross-correlates streams (energy low + builds queued = different signal than either alone)
- If signal: run claude -p (--effort medium) to compose the 3-sentence surface
- Writes to ops_ledger: event=horizon_scan, signal=yes|no, detail={pattern detected}
- Sends TG only when signal crosses threshold
