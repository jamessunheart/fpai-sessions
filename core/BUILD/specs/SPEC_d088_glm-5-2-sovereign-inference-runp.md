## Quantization strategy (critical for cost)
753B MoE with KTransformers offloading:
  - Active parameters per token: ~32B (MoE only activates relevant experts)
  - With KTransformers: experts on CPU RAM, attention on GPU
  - Minimum GPU: 1x A100 80GB for attention layers + CPU offload for experts
  - Alternatives if A100 insufficient:
    a. GGUF Q4_K_M quantized variant from unsloth/GLM-5-GGUF (check HF for GLM-5.2)
    b. AWQ 4-bit quantized (fits in 2x A100 80GB)
    c. GLM-4-9B as fallback (proven, runs on single A100, strong on code)

QUANTIZATION_PRIORITY:
  1. GLM-5.2 + KTransformers (1x A100, sovereign, true model)
  2. GLM-5.2 GGUF Q4 (multi-GPU, if KTransformers unavailable)
  3. GLM-4-9B full precision (1x A100, smaller but still strong open model)

The deploy script tries option 1, falls back automatically.
