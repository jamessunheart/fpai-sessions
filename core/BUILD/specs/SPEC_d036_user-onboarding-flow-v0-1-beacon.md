## Build
Build the user onboarding flow: from first beacon touch to a remembered, routed, CORA-earning user with a growing Agent Passport. Depends on: d034 (Hermes gateway), d035 (CORA policy). Beacon_id attribution closes the loop back to acquisition channel.

## New file: curator/onboarding/flow.py

Function: start_onboarding(hermes_msg: HermesMessage) -> HermesResponse
Called by Hermes gateway on first message from a new user_id.

Step 1 — Beacon context:
  Read beacon_id from HermesMessage. Load beacon_context from brain_index.beacons table   (beacon_id -> {source, campaign, expected_intent, opening_tone}).
  If no beacon: use generic opening.
  If beacon known (e.g., camp_zen_flyer): tilt first message toward that world.

Step 2 — Spark 3-question capture (conversational, not a form):
  Q1: 'What brought you here today?' (situation)
  Q2: 'What would feel like a win for you in the next 30 days?' (goal)
  Q3: 'How are you showing up right now — full energy, or running on fumes?' (energy/state)
  Ember extracts Agent Passport fields silently from natural answers.   User never sees a form. Profile builds from conversation.

Step 3 — Route to ONE specific next step (not a menu):
  Based on situation + goal + beacon: choose exactly one path:
  clarity_reflection | action_plan | camp_zen_invite | community_call |   fi_art_idea | service_match | human_guide | video_link
  Send that one thing. Not 9 options.

Step 4 — CORA first earn (gated on CORA_POLICY_LIVE env flag):
  If CORA_POLICY_LIVE=1: award onboarding CORA, notify user.
  If CORA_POLICY_LIVE=0: skip silently (policy not live yet — do not promise).

Step 5 — Agent Passport init:
  Write extracted fields to brain_index.agent_passports table:
  (user_id, goals, situation, energy, beacon_id, channel, onboarding_path, cora_balance,   proof_count, created_at, last_seen)
  Flag user as onboarded in user_channels.

Step 6 — Memory starts:
  Write onboarding session to brain_index.thread with surface=channel.
  From this point, Ember has context on every future message.
