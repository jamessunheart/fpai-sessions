# SPEC d202 — Merge-flow wedge-proofing (machine-written files must never orphan the index)

**Why (Ember 2026-07-05, root-caused live):** the autonomous build loop wedged *globally* — every queued spec (incl. d200) blocked — because `core/STATE/identity/ALIGNMENT.md` + `STORY.md` sat as orphaned `UU` unmerged index entries with **no merge/rebase in progress**, alongside dirty machine-written signal files (`core/BUILD/signals/awareness_reliability.{json,md}`, `core/STATE/HOT_STATE.md`). Manual recovery: `git checkout HEAD -- <those paths>` cleared it and d200 then merged clean (`rc=0`). This is a recurring class, not a one-off: machine-generators overwrite tracked files between merges, and `tools/merge/process_merge_requests.sh` never cleans them before `git checkout $BASE && git merge`, so a dirty tree fails the merge *before* `MERGE_HEAD` exists → the flow's `git merge --abort` no-ops ("no merge to abort") → orphaned unmerged entries persist → all future merges wedge.

## Design

1. **Pre-merge clean (prevent):** in `tools/merge/process_merge_requests.sh`, immediately before `git checkout "$BASE"`, reset the known machine-written paths to HEAD so a dirty tree can never block the switch/merge:
   `git checkout HEAD -- $MACHINE_GEN_PATHS 2>/dev/null || true`
   `MACHINE_GEN_PATHS` = a single sourced list: `core/STATE/HOT_STATE.md core/BUILD/signals/awareness_reliability.json core/BUILD/signals/awareness_reliability.md core/STATE/identity/ALIGNMENT.md core/STATE/identity/STORY.md` (identity mirrors are regenerated by `tools/sync_identity_to_repo.sh`; signals + HOT_STATE by their scanners — all safe to reset).
2. **Robust abort (contain):** replace the bare `git merge --abort` failure path with a fallback chain so orphaned unmerged entries can never survive a failed attempt:
   `git merge --abort 2>/dev/null || git reset --merge 2>/dev/null || git checkout -f "$BASE" 2>/dev/null || true`
   then assert `test -z "$(git ls-files -u)"` and, if not, hard-reset to the pre-merge snapshot tag already captured by `pre_merge_snapshot.sh`.
3. **Pre-flight guard (detect early):** at the top of the merge loop, if `git ls-files -u` is non-empty on entry (a prior run left the tree wedged), auto-clean via step 2's chain and emit one NOTIFY line rather than silently failing every spec.
4. **Root fix (stop the churn):** machine-only outputs should not fight the merge at all. Add `core/BUILD/signals/awareness_reliability.json` + `.md` to `.gitignore` IF no consumer reads them from a committed path (verify first — HOT_STATE + identity mirrors ARE read committed, so those stay tracked but are covered by steps 1–2). Document which machine-written paths are tracked-and-reset vs untracked.

## Guardrails

- Touches only the merge tooling + `.gitignore` + a sourced path list. No change to what gets merged, to `main`, or to the review gate.
- Resetting machine-written files is loss-free (regenerated ≤30 min); NEVER reset human-authored or build-branch content — only the enumerated `MACHINE_GEN_PATHS`.
- The pre-merge snapshot tag (existing) remains the rollback anchor; step 2 uses it as the last resort.

## Contract

Modifies `tools/merge/process_merge_requests.sh` (+ optional `tools/merge/merge_gate.sh` doc note), adds `tools/merge/machine_gen_paths.sh` (the sourced list), edits `.gitignore`. Reversible (revert branch). Independent review required. Register in `core/BUILD/REGISTRY.json`. Tests: simulate a dirty tree + a pre-existing `UU` entry, assert the flow cleans and merges instead of wedging. Do NOT push or merge.

## Done / Proof

A test that (a) dirties `HOT_STATE.md`, (b) plants an orphaned `UU` entry on an identity mirror, then (c) runs the merge flow against a trivial ready branch → the flow auto-cleans, merges the branch, and ends with `git ls-files -u` empty and the branch in `$BASE` history. Re-running with no dirt is a no-op. Proves the wedge class is dead.
