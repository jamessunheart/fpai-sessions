## Architecture (one line)
Traffic (ads/social/SEO) → content surfaces (/learn, /remember, /assessment 3-way A/B) → capture (pixel+leads.jsonl, utm=asset_id) → score/route (audit-as-router, BBB v1.4) → nurture (n8n sequences) → convert (Blueprint/Split/Partnership) → **GROWTH LEDGER** → nightly kill/breed + allocator → better generation. Every asset is a genome; every outcome a row; champions get distilled into WINNING_PATTERNS.md which seeds all future generation. Growth CCD = value-weighted pipeline per $+hour. Full design: vault `02_CONTEXT/Knowledge/Growth Stack Architecture.md`.
