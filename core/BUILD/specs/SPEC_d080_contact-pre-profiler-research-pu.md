# d080 — Contact pre-profiler — research public profiles before first
Auto-generated by the server build loop from answered decision d080.
## Build

James 2026-06-17: Before the system reaches out to anyone, it should research their
public presence (website, LinkedIn, Instagram, Twitter, published work) and build
a pre-contact profile. This profile:
  1. Tailors the outreach message with specific resonance points
  2. Seeds the AI's context so the first conversation already knows who they are
  3. Gets stored in brain_index so every future interaction builds on it

## Core principle: first contact should never feel generic
The system already found the person via signal (hashtag discovery or James's intro).
Now before sending anything, it learns who they are publicly, finds the 2-3 resonance
points most relevant to the full potential offer, and weaves those into the outreach.
The AI that talks to them already has context — the conversation starts warm.

## What to research (public sources only)
  1. Personal website (if exists) — who they are, what they offer, stated values
  2. LinkedIn — current role, past work, stated mission
  3. Instagram/Twitter — tone, recurring themes, recent posts, community
  4. Published work — articles, podcasts, YouTube (title-level scan)
  5. Any tool or project they're building (GitHub, product pages)

## Pre-contact profile schema (brain_index.contact_profiles)
  id SERIAL PRIMARY KEY
  contact_id INT REFERENCES contact_pool(id)
  researched_at TIMESTAMPTZ DEFAULT now()
  sources JSONB — {website: url, linkedin: url, instagram: url, ...}
  summary TEXT — 2-3 sentence who-they-are
  resonance_points JSONB — array of {point: str, why_relevant: str}
  suggested_subject TEXT — personalized subject line
  suggested_body TEXT — personalized first message
  raw_notes TEXT — full research dump
  confidence FLOAT — 0-1 how confident the profile is (low = public info sparse)

## The profiler agent
tools/outreach/pre_profiler.py
  Input: contact record from contact_pool (name, optional url hints, optional notes from James)
  Process:
    1. Fetch website if url provided
    2. Search: "{name} site:linkedin.com", "{name} instagram", "{name} {company}"
    3. Synthesize: who are they, what do they care about, what's the resonance with FP/conscious AI?
    4. Generate resonance_points (2-3 max, specific not generic)
    5. Draft subject + body using those resonance points + canonical outreach voice
    6. Store in contact_profiles
  Output: populated contact_profiles row + draft outreach message
