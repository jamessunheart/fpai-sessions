## Approach: Meta WhatsApp Cloud API (free tier)
Use Meta's WhatsApp Cloud API directly (no Twilio middleman, lower cost):
  - Free incoming messages always
  - Template messages for first outreach (must be pre-approved by Meta, ~24h)
  - Session messages (replies within 24h window) are free and unrestricted
  - Requires a Meta Business account + phone number (can use a virtual number)

Fallback if Meta approval is slow: Twilio WhatsApp sandbox for testing (immediate,
same webhook interface, just swap credentials when Meta approves).

## Architecture
tools/hermes/whatsapp_adapter.py
  - Webhook receiver at /webhooks/whatsapp (POST)
  - Verifies Meta webhook signature
  - Parses incoming message → extracts sender_wa_id, message text, media
  - Routes to Hermes gateway (same interface as Telegram adapter)
  - Sends reply via Meta Cloud API (session message within 24h, or template after)

tools/hermes/wa_sender.py
  - send_session_message(to_wa_id, text) — plain text reply within 24h window
  - send_template_message(to_wa_id, template_name, params) — for first outreach
  - generate_wa_link(pre_filled_text) → returns wa.me/NUMBER?text=... link
    (this is the zero-friction onboarding link James can share with contacts)

## Outreach flow for James's personal contacts
1. System generates personalized message per contact (name, shared context, the offer)
2. Two paths:
   PATH A (wa.me link): James forwards a pre-filled link → contact clicks → 
     system gets the inbound → probe agent takes over
   PATH B (template outreach): System sends template message directly IF WHATSAPP_LIVE=1
     (separate flag from OUTREACH_LIVE, gates specifically on WA send permission)
3. Once contact replies → probe_pool entry created → probe agent runs conversation
4. Same CORA credit, coach discovery, quality scoring as email path

## Contact list intake
tools/hermes/contact_loader.py
  load_contacts_from_csv(path) — reads name,channel,contact,notes
  load_contacts_manual(list_of_dicts) — for James pasting contacts directly
  Stores in brain_index.contact_pool:
    id, name, wa_id (or email/tg_handle), channel, source, notes, status, created_at
  Status: pending → outreach_sent → replied → in_probe → completed

## Probe agent integration
When WhatsApp message arrives:
  1. Check brain_index.contact_pool for existing record
  2. If new: create contact_pool entry (source='inbound_wa')
  3. Route to probe agent (same as email path)
  4. Probe agent replies via wa_sender.send_session_message()
  5. Conversation continues until probe completes

## Environment variables needed
  WA_PHONE_NUMBER_ID — from Meta Business dashboard
  WA_ACCESS_TOKEN — permanent system token from Meta
  WA_VERIFY_TOKEN — webhook verification token (we generate)
  WA_APP_SECRET — Meta app secret for X-Hub-Signature-256 verification
  WHATSAPP_LIVE=0 — separate flag; 0=receive only, 1=also send outbound template messages
