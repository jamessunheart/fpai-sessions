## Core principle: value retention over extraction
Traditional platforms extract value at every exchange (payment processor fees, platform cuts,
fiat conversion costs, bank friction). This system inverts that: optimize every exchange
toward internal currencies first. Off-ramp to fiat exists but the system never recommends it
when an internal path achieves the same outcome with less friction and zero extraction.

The more rich the internal economy becomes, the less anyone needs to leave it.

## Network roles (who the AI proactively recruits)
Not just seekers and coaches. Anyone who enhances network value:

  SEEKER      — working toward full potential. Brings: energy, feedback signal, growth story.
  COACH       — has navigated relevant terrain. Brings: skill, time, lived knowledge.
  BUILDER     — can create (code, design, content, curriculum). Brings: capability expansion.
  VALIDATOR   — can verify quality or outcomes. Brings: trust signal, proof.
  CONNECTOR   — high-reach network. Brings: reach, warm introductions.
  PATRON      — can fund or resource. Brings: capital, runway.
  ANCHOR      — embodies the mission publicly. Brings: credibility, story.

AI proactively identifies each role from conversations and public signals.
Beacon (discovery engine) gets role-specific search signals per role type.
Outreach message adapts to the role: Seeker gets the full potential offer; Builder gets
  "Sunheart is building infrastructure for human potential — your skills are directly relevant";
  Connector gets "The network is growing — your reach could shape who enters it."

## Multi-currency value ledger
New table: brain_index.value_ledger
  id SERIAL PRIMARY KEY
  at TIMESTAMPTZ DEFAULT now()
  from_identifier TEXT — who gave value
  to_identifier TEXT — who received value (can be 'system' or 'network')
  value_type TEXT — attention | time | knowledge | build | outcome | fiat | cora | crypto
  amount FLOAT — units of the currency
  currency TEXT — 'cora' | 'usd' | 'usdc' | 'hours' | 'attention_points' | 'outcome_credits'
  exchange_rate_to_cora FLOAT — equivalent in CORA at time of exchange (for unified reporting)
  description TEXT — what the exchange was for
  external_extraction FLOAT DEFAULT 0.0 — fees paid to outside the network (payment processor, bank)
  internal_flag BOOLEAN DEFAULT true — true = stayed inside network

Tracks every exchange: coaching session, build shipped, referral made, proof validated,
fiat received, crypto yield earned, attention contributed (comments, corrections, shares).

## Currency optimizer
tools/economy/currency_optimizer.py
  Input: exchange_type, amount, from_identifier, to_identifier
  Output: recommended_currency, reasoning, estimated_friction, estimated_extraction
  Logic:
    1. Can this be done entirely in CORA credits? (both parties have/want credits)
       → recommend CORA (friction=0, extraction=0)
    2. Can this use on-chain USDC? (both have wallets, amount >= $10)
       → recommend USDC (friction=low, extraction=network_fee ~$0.01)
    3. Does this require fiat? (payroll, legal, external vendor)
       → recommend fiat (friction=high, extraction=3-30%)
  The optimizer learns: track which recommendations were accepted and which outcomes resulted.
  Over time: routes that produce good outcomes with low extraction get weighted higher.

## Network value score (NVS)
Each network member gets a NVS: how much value have they added to the network vs extracted?
  NVS = (value_given_in_cora_equivalent) / (value_received_in_cora_equivalent + 1)
  NVS > 1: net contributor (earns higher capabilities, trust tier)
  NVS = 1: balanced
  NVS < 0.5: net extractor (system gently surfaces ways to contribute)
NVS is private to the member and the AI — not a public ranking. Used for routing decisions.

## Treasury integration
The existing crypto treasury (Gauntlet yield, HL positions) is the EXTERNAL reserve.
The CORA credit system is the INTERNAL economy.
Connection:
  When external capital enters (new fiat, yield income) → portion converts to CORA credits
    minted into the community pool (backs new credits with real value)
  When internal economy grows (more exchanges, higher NVS) → external reserve can stay smaller
    (less fiat needed because internal economy satisfies more needs)
  Treasury AI (Treasurer agent) watches the ratio: internal_circulation / external_reserve
    Healthy ratio means the network is becoming more self-sufficient

## Off-ramp minimization tracker
tools/economy/offramp_tracker.py
  Tracks weekly: total value exchanged, % that stayed internal, % that left as fiat/fees
  Target: reduce external_extraction_rate week-over-week
  When someone requests fiat off-ramp: optimizer first checks if their need can be met internally
    "You have 200 CORA credits. The coach session you wanted costs 75 credits.
     Would you like to use credits instead of converting to fiat?"
  Surface weekly: "Network retained 94% of value internally this week (up from 87% last week)"

## What unlocks with credits (the internal economy richness)
The richer the internal economy, the less fiat anyone needs. Build toward:
  Tier 1 (now): AI access, early features, community recognition
  Tier 2 (when coaches active): coaching sessions, peer review, mentorship
  Tier 3 (when builders active): custom builds, integrations, content creation
  Tier 4 (when Zen Village connected): physical stays, retreat access, village resources
  Tier 5 (full network): anything the network provides → credits first, fiat never if possible
