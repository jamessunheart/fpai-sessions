# d032 — Model redundancy router: T0 subscriptions -> T1 local -> T2 
Auto-generated by the server build loop from answered decision d032.
## Build
Remove the two single points of failure (claude -p and codex) by wrapping every AI call in a tiered model router. If T0 goes down, T1 (local ollama) carries the system. If both fail, T2 metered API kicks in under the $20/day cap. The system never silently fails — it degrades gracefully and restores automatically.

## New file: tools/intelligence/model_router.py

Primary function: call_model(prompt, task_type, tier_floor=0) -> dict
Returns: {response: str, provider: str, tier: int, latency_ms: int, cost_estimate: float}

Tier definitions:
  T0 — subscription CLIs ($0): claude -p for review/council/synthesis; codex for build
  T1 — local ollama on 162 ($0, always-on): ollama run llama3.1:8b or similar
      Install check: command -v ollama; model pull on first use
      Lower quality but zero external dependency
  T2 — metered API (emergency only, logged against $20/day cap):
      Anthropic API -> OpenAI API -> Gemini API (try in order, use first available key)
      Keys at: ~/.config/fpai/model_fallback.env (never commit)
  T3 — degraded mode: queue pauses, sends one TG alert, polls for T0 restoration every 5 min

Failure detection: subprocess timeout (30s for CLI calls) + returncode != 0 + auth error strings ('invalid bearer', 'not logged in', '401', 'rate limit')
On failure: log to ops_ledger event=model_fallback, from_tier=N, to_tier=N+1, reason=str
On T0 restoration: log event=model_restored, send TG 'Primary model back online'

## New file: tools/intelligence/provider_health.py

Function: check_provider_health() -> dict
Runs lightweight probe for each provider (no real prompt, just auth check):
  claude -p: echo 'ping' | claude -p --max-tokens 1 2>&1 (check exit code + no auth error)
  codex: codex --version 2>&1 (just checks binary alive)
  ollama: curl -s http://localhost:11434/api/tags (local HTTP check)
Returns: {claude: bool, codex: bool, ollama: bool, last_checked: timestamp}
Called by health_check.sh (wire in as new check). Writes to ops_ledger.

## Degraded mode (T3)
If all external providers (T0 + T2) are down but ollama is alive: continue on T1, log every call as degraded, send daily TG summary of degraded hours.
If ALL providers including ollama are down:
  - Pause build loop (touch /opt/fpai-build/.model_outage)
  - Send TG: 'All model providers unreachable. Build loop paused. Will auto-resume.'
  - Poll every 5 min; remove flag and resume when any provider responds
