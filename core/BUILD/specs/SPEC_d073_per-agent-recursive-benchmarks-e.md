# d073 — Per-agent recursive benchmarks — each agent measures itself,
Auto-generated by the server build loop from answered decision d073.
## Build

d057 measures all agents on 4 generic dimensions (code_quality, critique_depth, learning_speed,
reasoning). This does not reflect what each agent actually does. This build adds per-agent
specific benchmarks that each agent uses to measure its own performance, detect weakness,
and auto-generate improvement proposals. The recursive loop closes at the agent level.

## Architecture

Each agent gets:
  tools/benchmarks/{agent}_scorer.py  — collects current metric values from live data
  core/benchmarks/{agent}.md          — metric definitions, thresholds, improvement trigger rules
The benchmark runner extends d057, runs daily, writes time-series JSONL, detects drops/plateaus,
and auto-queues improvement specs into brain_index.decisions (build loop picks them up).

## Per-agent metrics (collect from live data sources)

### Beacon (discovery)
File: tools/benchmarks/beacon_scorer.py
  discovery_rate: probe_pool rows added per day (from probe_pool.created_at)
  source_quality: response rate per source (probe_sessions.engaged / probe_pool count per source)
  signal_precision: % of discovered contacts with discovery_score >= 0.7
  primary_metric: source_quality
  trigger: if source_quality < 0.4 for any source with >= 10 contacts → queue spec to improve/replace source

### Spark (routing)
File: tools/benchmarks/spark_scorer.py
  routing_completion: % probe_sessions where completed_spark = true
  drop_off_message: median message number where conversations end (from probe_sessions)
  conversation_continue_rate: % reaching message 3+ (proxy for routing clarity)
  primary_metric: routing_completion
  trigger: if drop_off_message median < 3 → queue spec to improve Spark opening question

### Ember (context steward / memory)
File: tools/benchmarks/ember_scorer.py
  correction_rate: brain_index.corrections rows per day (James corrections per session proxy)
  memory_staleness_days: days since identity/ALIGNMENT.md last modified
  session_start_coherence: manual proxy — read from ops_ledger events tagged 'session_start'
  primary_metric: correction_rate (lower = better)
  trigger: if correction_rate > 3/day rolling 7d avg → queue spec to improve memory or behavior pattern

### Hermes (channel gateway)
File: tools/benchmarks/hermes_scorer.py
  delivery_rate: probe_sessions sent / probe_pool contacted (once outreach live)
  response_rate: probe_sessions.engaged = true / probe_sessions sent per platform
  channel_efficiency: response_rate / estimated_cost_per_send per channel
  primary_metric: response_rate per channel
  trigger: if response_rate < 0.2 for any channel with >= 20 sends → queue spec to improve that channel

### Council (architecture debate)
File: tools/benchmarks/council_scorer.py
  proposal_build_rate: decisions where build_status='built' / total decisions proposed by council
  build_approve_rate: APPROVE reviews / total builds from council proposals
  build_success_rate: (proposal_build_rate * build_approve_rate) — composite
  convergence_rate: council debates where all 3 lenses converge / total debates
  primary_metric: build_success_rate
  trigger: if build_success_rate < 0.6 → queue council self-diagnostic spec

### Forge (build loop)
File: tools/benchmarks/forge_scorer.py
  Read from: core/BUILD/REGISTRY.json + core/BUILD/reviews/
  first_pass_approve_rate: APPROVE on first review / total builds (no prior REQUEST_CHANGES)
  revert_rate: auto-reverted merges / total merges (from ops_ledger)
  cycle_time_hours: hours from spec_written to merged (decisions timestamps)
  primary_metric: first_pass_approve_rate
  trigger: if first_pass_approve_rate < 0.6 rolling 7d → queue spec to strengthen SESSION_CONTRACT

### Steward / Ledger (ops truth)
File: tools/benchmarks/steward_scorer.py
  measurement_coverage: unique event types in ops_ledger / known event types (from a manifest)
  ledger_freshness_hours: hours since last ops_ledger row
  correction_to_build_lag_hours: hours from correction captured to spec queued (rolling avg)
  primary_metric: measurement_coverage
  trigger: if coverage < 0.8 → queue spec to instrument uncovered event types

### Loop (whole organism)
File: tools/benchmarks/loop_scorer.py
  improvement_velocity: week-over-week delta on each agent's primary_metric (sign + magnitude)
  recursive_depth: how many improvement cycles each agent has completed (count of auto-queued specs built)
  north_star_cost_per_task: read from ops_ledger cost rows / accepted build count (proxy for tasks)
  primary_metric: improvement_velocity (want positive week-over-week for all agents)
  trigger: if any agent flat (|delta| < 0.02) for 14 days → escalate to council for architectural review

## Time-series storage

  One row per agent per daily run:
  {"agent": "forge", "run_date": "2026-06-17", "primary_metric": 0.72,
   "metrics": {...all values...}, "trigger_fired": false, "spec_queued": null}
This is the time-series that shows improvement over time. The story: baseline Day 0 →
improvement trajectory → proof that each agent learns from itself.

## Improvement proposal generator
tools/benchmarks/improvement_proposer.py
  Reads per_agent_scores.jsonl for triggered agents
  Uses claude -p (--effort low) to draft an improvement spec based on:
    - The specific metric that triggered
    - The agent's blueprint (docs/blueprints/{agent}.md)
    - Recent corrections or revert events related to this agent
  Queues spec via curator.decisions.queue_build()
  Logs: {"agent": "forge", "trigger_metric": "first_pass_approve_rate",
         "value": 0.54, "spec_queued": "dNNN", "reasoning": "..."}
  Cost: ~$0.02 per proposal (--effort low, short prompt). Rate-limit: max 2 specs/agent/week.

## Runner (extends d057)
tools/benchmarks/run_all_benchmarks.py
  Runs all 9 scorers sequentially (error-isolated — one failure doesn't stop others)
  Writes to per_agent_scores.jsonl
  Calls improvement_proposer.py for any triggered agent
  Appends to ops_ledger: event=benchmark_run, agent={name}, primary_metric={value}
  Kill switch: BENCHMARKS_DISABLE=1
