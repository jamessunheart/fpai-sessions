Function: create_checkout_session(user_id, tier) -> str (checkout URL)
  Creates Stripe Checkout session for the user.
  Passes user_id as metadata (links payment to user_agent).
  Returns the Stripe-hosted checkout URL.
  Bot sends URL to user when they request /upgrade or hit a tier gate.

Function: handle_webhook(payload: bytes, sig: str) -> None
  Verifies Stripe webhook signature.
  Handles events:
    checkout.session.completed -> update user_agents.tier + stripe_customer_id + subscription_status=active
    customer.subscription.updated -> sync tier if plan changed
    customer.subscription.deleted -> set subscription_status=cancelled, tier=free after grace
    invoice.payment_failed -> set subscription_status=past_due, send TG warning to user
  Logs all events to ops_ledger: event=stripe_webhook, type=X, user_id=Y, tier=Z.

Function: get_portal_url(user_id) -> str
  Returns Stripe Customer Portal URL (user manages their own subscription, cancel, update card).
  Bot responds to /billing command with this URL.

## Tier definitions (seed Stripe Products/Prices manually first time)
Free: 0/mo. 10 messages/day. search_web only. No CORA bonus.
Basic: $9/mo. 100 messages/day. email + calendar capabilities. +100 CORA on subscribe.
Pro: $29/mo. Unlimited. All capabilities. +500 CORA on subscribe. Priority routing.

## Upgrade prompts (when tier gate hit)
On free session limit hit: 'You've used your 10 free messages today. Basic ($9/mo) gives you 100/day + email + calendar. [Upgrade] or come back tomorrow.'
On capability gate hit: '[capability] needs Basic or Pro. You're on Free. [Upgrade to Basic - $9/mo] or [See what Basic unlocks].'
Tone: door, not wall. Never 'you can't'. Always 'you could'.

## CORA on subscription
On checkout.session.completed:
  basic: award 100 CORA to user. Notify: 'Welcome to Basic — you earned 100 CORA.'
  pro: award 500 CORA. Notify: 'Welcome to Pro — you earned 500 CORA.'
  Calls record_event(beacon_id, 'paid_conversion') if beacon_id on user_agent.

## Bot commands

/billing -> sends Customer Portal URL
