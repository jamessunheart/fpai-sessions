# 🤖 AUTONOMOUS FULFILLMENT PROTOCOL (AFP)

> **Purpose:** Define the logic for safely routing missions between Autonomous AI execution and Human execution.
> **Authority:** @core/knowledge/CONSTITUTION.md
> **Owner:** System Architect

## 1. THE CORE LOGIC
The system is designed to be **Self-Healing** and **Self-Extending**.
Missions are generated by the **Reflex** (Autonomic Nervous System).
They must be routed to the most efficient executor: **AI** (Speed) or **Human** (Creativity/Safety).

### 🚦 The Triage Gate
Every new mission (`missions/*.md`) is evaluated by `_scripts/triage_missions.py`.

| Criteria | Auto-Queue (AI) | Human-Queue (Operator) |
| :--- | :--- | :--- |
| **Security Level** | `LOW` (Public/Sandbox) | `MEDIUM` or `HIGH` (Secrets/Infra) |
| **Complexity** | `SIMPLE` or `MODERATE` | `COMPLEX` (Architecture/Novelty) |
| **Risk Factor** | No `DELETE`/`DROP` actions | Irreversible actions |
| **Context** | Clear `Steps` & `Deliverables` | Vague or Strategic goals |

## 2. EXECUTION FLOW

### 🟢 PATH A: AUTONOMOUS BUILDER
**Trigger:** Mission tagged `[AUTO-CANDIDATE]`
1.  **Claim:** System locks the mission file.
2.  **Build:** `auto_build.py` reads the Spec.
    *   Generates code/files based on `EXECUTION STEPS`.
    *   Writes to the codebase.
3.  **Verify:** System runs the `VERIFICATION` script/check defined in the Spec.
4.  **Result:**
    *   ✅ **PASS:** Status -> `COMPLETED`. Notify Dashboard.
    *   ❌ **FAIL:** Status -> `FAILED`. Escalate to Human.

### 🟡 PATH B: HUMAN OPERATOR
**Trigger:** Mission tagged `[HUMAN-REQUIRED]` or `[ESCALATED]`
1.  **Notification:** Dashboard highlights the mission as "Needs Operator".
2.  **Claim:** Operator runs `session-claim.sh`.
3.  **Execute:** Operator manually writes code/config.
4.  **Verify:** Operator marks `COMPLETED`.

## 3. SAFETY PROTOCOLS
1.  **The Sandbox:** Auto-Builder cannot access `/etc/` or root-level configs without explicit High-Security override (which forces Human Review).
2.  **The Rollback:** If Verification fails, `auto_build.py` must attempt to revert changes (git stash/reset).
3.  **The Paper Trail:** All Auto-Actions are logged to `core/INTELLIGENCE/ACTION_LOG.md`.

## 4. OPTIMIZATION LOOP
*   If a Human completes a `SIMPLE` mission repeated >3 times, the System proposes an Automation Script to handle it next time.
