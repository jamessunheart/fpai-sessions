## Why this pack exists

The Counsel critique of Allocation Platform v0.1 (2026-05-12) returned a CRITICAL gap:

> *"The PMA wall is asserted, not established. An unformed PMA with no written membership agreement, no defined admission process, and no documented religious covenant is not meaningfully different from an unregistered securities offering with 'members only' written on the door."*

Treasury v0.10 §What Needs to Be Formalized + §Preconditions lists the same gaps as the legal foundation for **everything** — not just the Allocation Platform. Brand Tokenization v0.4 CONVERGED treats counsel engagement + §501(d) analysis + state registration as required deliverables, but those deliverables presuppose a documentary PMA exists for Counsel to opine on.

CORA Nation already exists as **religious community + lived practice + doctrinal canon**. What this pack adds: the formal **membership-association layer** — the documents that turn doctrine into a legally-recognized PMA the IRS, state regulators, and Counsel can examine.
