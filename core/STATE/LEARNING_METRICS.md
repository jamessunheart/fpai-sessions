# LEARNING_METRICS — the conversion-efficiency spine

**Status:** canonical model adopted 2026-06-30 (Learning Intelligence Flywheel, James + GPT synthesis).
**One equation:** `Future Capability = Current Capability × Learning Efficiency`. Everything below exists to raise the multiplier.

> **North-star metric: Rate of Improvement (Learning Rate / LR).** Not "how capable are we?" but "how fast are we getting better?" Capability is a stock; learning is the flow. We optimize the flow. **Awareness % is demoted** from THE number to one sub-probe feeding LR.

## The weakest-conversion rule

A pipeline `100→95→90→20→95` performs at **20**. Improving a strong stage 5% is wasted motion. **Improve the weakest conversion first.** Right now our weakest is **VPI/VCR — the value conversions — because Reality (real users) is starved, not because learning is weak.** Conclusion: the highest-leverage move is not more learning infrastructure; it is getting real users so the right half of the flywheel has data to optimize. (See NOW.md d069 outreach engine — built, `OUTREACH_LIVE=1` not yet flipped.)

## The 4-level priority ladder (orders ALL autonomous work)

1. **NEVER BREAK** — safety + truth. Accuracy, honesty, system safety, secure deploys. Never compromised for any gain below.
2. **IMPROVE LEARNING** — memory, evaluation, reflection, curiosity, benchmarks. A faster learner beats a bigger system.
3. **IMPROVE EFFICIENCY** — cheaper compute, routing, token reduction, caching. Efficiency after learning avoids waste.
4. **SCALE** — more agents, more automation, more users, more servers. Scale multiplies what already works.

Autonomous work picks the highest-level unmet need first. Never skip up the ladder to scale something unsafe or unmeasured.

## Honesty gate (load-bearing)

Do NOT fabricate the starved metrics. VPI/VCR/RR stay **instrumented-but-unpopulated** until real users + revenue exist — and that emptiness is itself the signal pointing at the weakest conversion. A metric we can't truthfully populate is reported as `unknown`, never estimated to look good. Reality cannot be faked; neither do we.
