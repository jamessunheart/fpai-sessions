## 🔄 Update Protocol

1. When a Loop ships a user-visible capability, add an entry under the right category with the date.
2. When a capability is paused, deprecated, or retired, move it to **Deprecated / Retired** with the date.
3. When a status changes (🟡 → 🟢, ⚪ → 🟢), edit in place — don't duplicate.
4. Keep entries one line. The story lives in the proofs (`core/INTENT/AGREEMENTS/proofs/`); this file is the index.
5. Run `SERVICES/sunheart-brain/ingest/sync_now_to_brain.sh` to push NOW.md + this file to the brain server. `/capabilities` will reflect changes within seconds of the next sync.
6. `/capabilities <category>` filters to one category (game / brain / inquiry / money / trading / infra / village / bots / deprecated).

*If a capability isn't in this file, it doesn't exist — at least not as something the system can claim. Add it or admit it.*
