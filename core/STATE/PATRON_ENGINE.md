## THE GOVERNING FEAR = THE GUARDRAIL (James)

> "I'm afraid of taking people's money and not immediately having something of utility."

This fear is **correct** and it is the design rule:

- **Only sell access to what is already standing.** Never pre-sell the dream.
- Donated/invested money builds *more* — but you never *sell* the "more."
- **Sell the now. Gift the growing.**
- Immediate utility = honest AND not-a-security. Conscience and the SEC want the same thing.

## THE THREE LEGAL ANIMALS (keep them separate)

| Framing | What it legally is | Treatment |
|---|---|---|
| Gift + acknowledgment only | **Donation** (508c1a) | Tax-deductible · clean |
| Pay → get access/utility now | **Membership / sale** | NOT deductible · clean revenue |
| Give → value compounds b/c *we* invest | **Security** (Howey) | ⛔ danger zone — avoid this framing |

★ The phrase **"compounding utility value"** is what converts a membership into a security in a regulator's eyes. The compounding can *happen* — but only as a consequence members discover, never a return you advertise.

**Two clean doors, same story page:**
1. **Membership / Access tiers** → revenue (fast, not deductible)
2. **Patron donations** → deductible, story-driven, acknowledgment-only

## THE FLYWHEEL (where compounding lives, cleanly)

Every event is also **content**:

```
Patron contributes → receives real utility (event/access/stay) tonight
     → event is filmed → becomes the build-in-public show
     → show recruits the next wave of patrons
     → donated resources build more standing utility (the store grows)
     → bigger/better next gathering → repeat
```

Each turn pays in **cash** AND in **the story that fills the next one**. Compounding as a *consequence*, never an *advertised return*.
